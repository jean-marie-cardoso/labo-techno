État = comment est le feu maintenant. Événement = ce qui vient de se produire.

Le minuteur envoie "fin" tout seul. Tu n’as pas à programmer l’attente. Un deuxième clic pendant le vert doit laisser le feu vert, sans relancer les 4 secondes.

2 Compléter ton programme

À deux : un élève lit la règle et explique les trois choix ; l’autre les écrit. Échangez les rôles pour les essais.

La première condition est déjà écrite. Elle se lit :

SI le feu est à l’arrêt ET que l’on demande le passage, ALORS le nouvel état est « passage ».
Comprendre les lignes du code
function transition(etat, evenement)
Ce bloc reçoit l’état actuel et l’événement. Il doit renvoyer le nouvel état du feu. Garde cette première ligne.
if
« Si » : on vérifie une condition.
etat === "arret"
Vérifie si l’état est égal à « arret ». Les trois signes = servent à comparer.
&&
« Et » : les deux conditions doivent être vraies en même temps.
return "passage";
Renvoie « passage » comme nouvel état. La décision est terminée.
return etat;
Si aucune condition précédente ne convient, garde l’état actuel. Cette ligne reste après les deux conditions.
{ } et " "
Les accolades encadrent les instructions. Les guillemets encadrent un mot. Écris "arret" sans accent dans le code.

À faire : remplace les trois mots en MAJUSCULES dans la deuxième condition. Garde les guillemets et les autres signes.

  1. ETAT_AVANT : dans quel état est le feu juste avant la fin du délai ?
  2. EVENEMENT : quel événement le minuteur envoie-t-il ?
  3. ETAT_APRES : quel état doit être renvoyé ?
Indice 1 · Les mots disponibles

Les états sont "arret" et "passage". Les événements sont "demander" et "fin". Aide-toi des deux flèches en haut.

Indice 2 · Traduire la règle en français

SI le passage est autorisé ET que le délai se termine, ALORS le feu revient à l’arrêt. Associe chaque morceau de cette phrase à un des trois mots à remplacer.

Complète les trois mots, puis lance ton programme.
Si un message d’erreur apparaît
  • Erreur de syntaxe : vérifie les guillemets, les parenthèses et les accolades, puis compare avec la première condition.
  • État renvoyé incorrect : après return, utilise exactement "arret" ou "passage".
  • Le feu reste vert : regarde la deuxième condition. La ligne return etat; doit rester tout à la fin.

Ton feu à tester

Après chaque changement de code, clique sur « Lancer mon programme ». Le feu repart au rouge.

3 Prouver que ton programme fonctionne

Fais ces essais dans ton feu. Le tableau automatique vérifie les décisions ; ici, tu vérifies aussi les clics et le temps.

  1. Premier clic : le feu devient vert et le compte à rebours démarre.
  2. Pendant le vert : clique quand il reste 2 secondes. Le compteur ne repart pas à 4.
  3. Fin du délai : le feu revient au rouge sans nouveau clic.
  4. Nouveau passage : clique encore. Un nouveau cycle de 4 secondes commence.

Sur ta feuille : pour chaque essai, note l’action, le résultat attendu et ce que tu as observé. Si cela échoue, indique ce que tu as corrigé et recommence.

Pour expliquer ton programme au binôme

Montre la ligne qui fait passer au vert, puis celle qui fait revenir au rouge. Explique pourquoi cliquer pendant le vert ne change pas l’état.
