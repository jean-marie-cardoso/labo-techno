Programmer une application mobile

Une application suit une demande depuis son envoi jusqu’à sa confirmation. Programme les transitions autorisées. La présentation est fournie ; tu écris la logique. Le programme de départ ne répond pas encore aux règles.

1 Les règles à programmer

  • État 0 + Demander → état 1.
  • État 1 + Confirmer → état 2.
  • État 2 + Réinitialiser → état 0.
  • Toute autre combinaison garde le même état.

Sur ta feuille, dessine les boutons et les messages. Indique ce que chaque action doit produire.

2 Écrire et essayer

À deux : l’un modifie le programme, l’autre prépare les essais. Échangez les rôles après le premier test. Le programme de départ est volontairement incomplet.

if signifie « si » ; === compare ; && signifie « et » ; return renvoie le résultat. Garde les accolades et les guillemets.

Aide sur les commandes

Complète le code, puis lance les essais.

3 Tester et corriger

Le tableau de vérification compare chaque règle. Teste aussi les boutons dans l’aperçu : le bon calcul ne suffit pas à vérifier toute l’application.

  1. Confirmer et Réinitialiser à l’état 0 : aucun changement.
  2. Demander : état 1. Demander encore ou Réinitialiser : état 1.
  3. Confirmer : état 2. Demander et Confirmer : état 2.
  4. Réinitialiser : état 0. Rejouer le parcours entier.

Sur ta feuille : entrée ou action → résultat attendu → résultat obtenu → correction. Relance ton programme après chaque modification.

4 Conserver ton travail

Teste les deux largeurs. Enregistre ton application et ouvre le fichier obtenu. Chacun du binôme modifie le code et explique un test. Si une tablette est disponible, vérifie aussi le toucher.
