MISE EN PRATIQUE

Programmer une application mobile

SUIS TA FICHE

Q1 · Identifier les données

Classe les données : état (0, 1, 2), événement reçu et texte affiché. Utilise entier ou texte. Un compteur de demandes sera aussi un entier.

SUIS TA FICHE

Q3–Q6 · Préparer ton programme

  1. Q3 : écris les trois règles avec « si… et… alors… ». Dans les autres cas, l’état doit rester identique.
  2. Q4 : donne un message pour chaque état. L’affichage est séparé du calcul du nouvel état.
  3. Q5 : pars de 0, puis essaie Confirmer, Demander, Demander, Confirmer, Réinitialiser. Note les cinq états.
  4. Q6 : propose quand compter une nouvelle demande, pour ne pas compter deux fois un double clic.
SUIS TA FICHE

Q8 · Expliquer et adapter ton application

Traduis en français une ligne if… return… de ton programme. Dans le studio, teste les largeurs téléphone (360 px) et tablette (768 px). Vérifie que textes et boutons restent visibles. Ouvre ensuite ton fichier HTML enregistré.

Avant de terminer

Vérifie tes numéros de réponses, tes unités et les observations qui justifient tes conclusions.

Modèles scolaires et données du dossier de cours. Aucun résultat personnel enregistré ou envoyé. Les explications et conclusions restent sur papier.
