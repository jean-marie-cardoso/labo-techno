Q1 · COMPRENDRE LES BITS

Des données écrites avec 0 et 1

Une donnée est une information : un texte, un nombre, une image…

Un bit est un chiffre qui vaut 0 ou 1. Un octet est un groupe de 8 bits.

Pour écrire un nombre en binaire, chaque place possède une valeur : son poids. On additionne les poids des places marquées 1. Une place marquée 0 n’ajoute rien.

Exemple expliqué : écrire 10

10 = 8 + 2. On met 1 sous 8 et sous 2, puis 0 dans les autres places.

00001010 représente donc 10 sur 8 bits. On garde les zéros à gauche pour avoir huit places.

Essaie les huit places

Clique sur un bit. Observe ce qu’il ajoute ou retire à la somme.

Que veut-on transmettre ? Trois cas différents

La station peut envoyer une température, signaler une alerte ou envoyer une lettre. Les trois utilisent des bits, mais on ne les prépare pas de la même façon.

1 · Une température : transmettre une quantité

Le capteur indique 25 °C. Il faut comprendre deux éléments :

  • 25 indique combien : c’est la valeur mesurée.
  • °C signifie « degrés Celsius » : c’est l’unité de température. Le nombre 25 seul pourrait aussi désigner 25 mètres ou 25 secondes.

Pour Q1, tu convertis le nombre 25 en binaire, avec les huit poids. L’unité °C sert à interpréter ce nombre comme une température.

2 · Une alerte : transmettre une réponse oui ou non

La station pose une question : « Un problème est-il détecté ? » Elle n’envoie pas une quantité, mais l’un des deux états possibles :

SituationRéponse à la questionCode envoyé
Un problème est détecté.Oui : l’alerte est vraie.1
Aucun problème n’est détecté.Non : l’alerte est fausse.0

Une donnée qui ne peut prendre que vrai ou faux s’appelle un booléen. Un seul bit suffit : il offre exactement deux possibilités, 0 et 1.

Dans Q1, « alerte vraie » signifie donc alerte active : un problème est signalé. Vrai ne veut pas dire « tout va bien ».

  2. On lit dans la table le nombre qui lui correspond : 65.
  3. On convertit ce nombre en binaire : 65 = 64 + 1. On met 1 sous les poids 64 et 1.

À retenir : nombre → conversion en binaire ; alerte → vrai ou faux ; lettre → table de correspondance, puis conversion du nombre.

Q2 · COMPRENDRE LES PIXELS

Une image composée de petites cases

Un pixel est une petite case d’une image numérique. Ici, un pixel est soit blanc, soit noir : 0 = blanc ; 1 = noir.

Un seul bit suffit donc par pixel. La taille dépend du nombre total de cases, y compris les cases blanches.

Exemple avant l’exercice

Une image de 2 lignes et 2 colonnes contient 2 × 2 = 4 pixels. À un bit par pixel, elle utilise 4 bits.

Pour passer des bits aux octets, divise le nombre de bits par 8.

Q3–Q4 · COMPRENDRE LE TRAJET

Un paquet avance de routeur en routeur

Un réseau local relie les appareils d’un même lieu. Un commutateur (switch) relie des appareils dans ce réseau. Internet relie des réseaux entre eux.

Un serveur est un ordinateur qui reçoit une demande ou fournit un service. Ici, A envoie une mesure au serveur S, situé dans un autre réseau.

Les données circulent en paquets : de petits blocs de données accompagnés d’informations pour les acheminer, dont une adresse de destination.

Un routeur transmet le paquet vers un autre réseau. Sa table de routage lui indique vers quel voisin l’envoyer : c’est le prochain saut.

Destination et prochain saut : deux choses différentes

Pour aller au collège en bus, le collège est la destination ; le prochain arrêt n’est qu’une étape. Pour un paquet, la destination reste S ; le prochain saut dépend du routeur où il se trouve.

Le cercle jaune montre où se trouve le paquet. Les liaisons parcourues deviennent orange.

Q5–Q6 · COMPRENDRE L’ENVOI

Combien de temps faut-il pour envoyer un fichier ?

La taille indique la quantité de données à envoyer. Le débit indique combien de bits peuvent être envoyés chaque seconde.

bits/s signifie « bits par seconde ». Un débit n’est pas une durée.

Exemple expliqué avec d’autres valeurs

Un fichier de 1 000 octets est envoyé à 4 000 bits/s.

  1. Convertir en bits : 1 000 × 8 = 8 000 bits.
  2. Diviser par le débit : 8 000 ÷ 4 000 = 2 secondes.

Durée en secondes = taille en bits ÷ débit en bits/s

Q7–Q8 · COMPRENDRE LE TABLEAU PARTAGÉ

Envoyer, exploiter et partager des mesures

On reprend les six durées d’ouverture du volet de 3S07. Le serveur peut conserver ces mesures dans un fichier que le groupe consulte.

Un tableur calcule à partir de cellules : les lettres repèrent les colonnes, les nombres repèrent les lignes.

Un fichier CSV est un tableau enregistré en texte. Le point-virgule sépare les colonnes ; la virgule sépare ici les décimales.

Une moyenne résume plusieurs valeurs : somme des valeurs ÷ nombre de valeurs. Exemple : 2 s, 3 s, 4 s → (2 + 3 + 4) ÷ 3 = 3 s.

Qui peut lire ? Qui peut modifier ?

Le droit lecture permet de consulter le fichier sans le changer. Le droit modification permet de le lire et d’en changer le contenu.

Une donnée personnelle concerne une personne identifiable : nom, adresse personnelle, numéro de téléphone… Un tableau de durées peut utiliser un numéro de groupe.
