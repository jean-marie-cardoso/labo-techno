# Le labo techno

44 activités de technologie pour les 5e, 4e et 3e, liées aux fiches de cours 2026–2027.

- Illustrations originales de type manuel scolaire : objets et outils reconnaissables, sans échelle.
- Une adresse directe par séquence : `/5/01/`, `/4/01/`, `/3/01/`, etc.
- Manipulations et observations à l’écran ; raisonnements, réponses et conclusions sur papier.
- Aucun menu entre activités, aucune zone de réponse rédigée, aucun corrigé ou contrôle publié.
- Programmation dans Scratch ; les pages proposent des expériences et des comportements à observer.
- Sans compte, sans bibliothèque externe, sans collecte des réponses par le site.

Les données et modèles sont pédagogiques. Les expériences simulées ne prouvent pas la réalisation d’une fabrication ou d’une mesure réelle.

## Publication

Le workflow GitHub Actions publie uniquement `public/`. Il se lance manuellement depuis Actions → Publier le labo techno. GitHub Pages doit être configuré sur GitHub Actions.

Ce dépôt contient exclusivement les fichiers destinés à la publication. Les cours Word/PDF, contrôles, corrigés, sauvegardes et catalogue professeur restent dans le dossier de travail local.

Documentation : [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) et [publication par workflow](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
